# The test suites, in the order they run: `scripts/haxeon dev test quick|wave|ci|full` (scripts/test.sh runs `ci`, scripts/gate.sh the
# others). Before the first suite the runner builds the native runtime and resolves the compiler entry point, the compiler, the build tool
# and the CLI from the tool cache, and exports them (HAXEON_MAIN_HL, HAXEON_COMPILER_HL, HAXEON_BUILD_HL, HAXEON_HASHLINK_DIR) with
# HAXEON_NATIVE_READY=1, so every suite of one run uses the same builds.
#
#   <name> <groups> [options] -- <command>
#
# groups   a comma list of quick, wave, ci. `quick` selects quick suites, `wave` quick and wave, `ci` the ci suites (what CI runs) and
#          `full` all three. A suite in several groups runs once.
# command  a bash command run from the repository root, stdout and stderr together; {jobs} is the job count (--jobs). HAXEON_SUITE_OUT
#          is an empty directory of the suite's own (in the run directory): a suite that may run beside another writes there, not to
#          a fixed path under out/ (scripts take it as haxeon_suite_out from scripts/lib/env.sh, test mains through tests/SuiteOutput.hx).
#
# options
#   lane=NAME           suites of one lane run one after another, in the background, from where the first of them is listed; the rest
#                       of the list goes on meanwhile. Their logs print at the end. List a lane's suites together.
#   pool=NAME           consecutive suites of one pool run at once, at most min(jobs, 6) at a time; the list waits for the pool. Their
#                       logs print when the pool ends, in list order.
#   requires=TOOL       skip, and say so, without the tool. Known tools: wasmtime (WASMTIME, .tools/wasmtime-47.0.0 or PATH).
#   unless-env=NAME     skip when the variable is 1.
#   fresh-native        run without HAXEON_NATIVE_READY, so the suite's own native build really configures and builds.
#   cli-launcher        route `haxe --run tools.HaxeonCli` through the prebuilt CLI (scripts/test-cli-launcher.sh), unless HAXEON_HAXE
#                       is already set.
#
# Two suites must not share a lane or a pool when one writes files the other reads; say why next to a lane or pool that looks
# combinable but is not.
